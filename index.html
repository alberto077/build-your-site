Step 1

How AI models work (the 5-minute version)

🔮 It predicts

An AI chatbot writes by guessing the next word over and over, based on patterns it learned from a huge amount of text, including millions of websites. That's why it's good at writing HTML.

🧠 It only knows what you tell it

It doesn't know you. The more specific you are about colors, mood, sections and content, the better the result. Vague prompt, generic site.

📏 It has a memory limit

Very long chats make it forget earlier details. If things get weird, start a new chat and paste in your latest code.

🎲 It's random-ish

The same prompt gives a different result each time. If you don't like it, regenerate or ask for "3 different versions."

🙃 It makes mistakes

AI can sound confident and still be wrong. Always open your site and check that it really works.

🎨 You're the director

Think like an art director giving notes: "make the title bigger," "less purple," "feel more like a skate shop."

A great prompt has 4 parts

  1. Role. "You are a web designer."
  2. Goal. "Make my personal website as one HTML file."
  3. Content. Your name, about you, your interests, your projects.
  4. Style. Colors, fonts, mood, and a reference ("like a Nintendo game menu").
Step 2

Pick your AI tool (all free)

Check the age rules. ChatGPT and Gemini allow ages 13+ with a parent's permission if you're under 18. Claude requires you to be 18 or older. If you're under 18, use ChatGPT or Gemini. The prompts here work the same in all of them.
ToolGood forHow to see your site
Gemini
Google account		 Free Canvas shows a live preview of your website as it's built. Turn on Canvas in the prompt bar, then click Preview.
ChatGPT
free account		 Generous free chat limits, good at following edit requests. Copy the code into a file called index.html and open it (see "Save your file" below).
Claude
18+ only		 Very strong at design. Free plan includes Artifacts, which show a live preview. The preview appears next to the chat. Use the download button to get the file.

Make your free messages last

  • Free plans have limits. Claude's free plan, for example, resets every few hours. Don't waste messages on "hi."
  • Put everything into one big first prompt (use the builder below).
  • Combine edits: "Make the title bigger AND change the green to orange AND add a footer" counts as one message, not three.
  • Hit a limit? Copy your latest code, switch to another tool, paste it in and say "Here's my website code, please keep going."
  • Save your code often so nothing gets lost.

    Step 4
    
Remix it: copy-paste edit prompts

    
Send these after your first result. Combine 2–3 in one message to save your limits.

    

      
🎨 Colors
Change the color scheme to [colors]. Keep everything else the same.

      
✨ Motion
Add subtle animations: sections fade in as I scroll and buttons gently grow when I hover.

      
📱 Phone check
Make sure it looks great on a phone screen. Nothing should be cut off or need sideways scrolling.

      
➕ New section
Add a new section called "[name]" with [what goes in it], styled to match the rest of the site.

      
🌗 Dark mode
Add a light/dark mode toggle button in the top corner.

      
🎲 Surprise me
Give my site one creative, fun detail that makes it feel unique to me, based on my interests.

      
🔁 3 versions
Show me 3 very different design directions for the top of my site, then I'll pick one.

      
🧩 Full code
Please give me the complete, final index.html file with all changes, not just the changed parts.

    

    
Pro tip: always finish with the 🧩 Full code prompt before you copy. AI sometimes sends only the changed part.

  


  
  

    Step 5
    
Go live on GitHub Pages (free)

    
GitHub is where developers store code. Its "Pages" feature turns a file into a real website. You need to be 13+ to make an account.

    
    
      
  1. Go to github.com/signup and make an account. Your username becomes your website address, so choose a good one with no real last name needed.
    2. 
      
  2. Click the + (top right), then New repository.
    3. 
      
  3. Name it exactly yourusername.github.io (with your real username). Set it to Public and click Create repository.
    4. 
      
  4. Click uploading an existing file, drag in your index.html, then click Commit changes.
    
        No file? Click creating a new file instead, name it index.html, and paste your code in.
    5. 
      
  5. Go to Settings → Pages. Under "Branch," pick main and click Save (it may already be set).
    6. 
      
  6. Wait 1–2 minutes, then visit https://yourusername.github.io. You're on the internet! 🚀
    7. 
    

    
Updating later

    
Open your repository, click index.html, click the ✏️ pencil, paste your new code, then click Commit changes. The site updates in about a minute.

  


  
  

    
Something broke? 🛠️

    

      
My site shows a 404 page
Wait 2 more minutes. Then check the file is named exactly index.html (lowercase, not index.html.txt) and the repository is named yourusername.github.io.

      
My site shows the code as plain text
On Mac TextEdit, use Format → Make Plain Text before saving. Or skip the editor and paste straight into GitHub's "create new file" page.

      
Half my site disappeared after an edit
The AI only sent part of the code. Use the 🧩 Full code prompt.

      
Images don't show
AI can't add your real photos for you. Use emoji or shapes, or upload an image to your repository and ask the AI to use photo.jpg.

      
I hit my message limit
Copy your latest code, switch tools (Gemini ↔ ChatGPT), paste it in and keep going.

      
The AI is going in circles
Start a new chat. Paste your code with one clear request: "Here's my website. Change only X."

    

  


  
  

    
Words you'll hear (the "tech stack")

    
You don't need to write any of this today, but now you'll know what the AI is making.

    

      
HTML
The structure: headings, paragraphs, buttons. Like the skeleton of your site.

      
CSS
The style: colors, fonts, spacing, animations. The clothes and makeup.

      
JavaScript (JS)
The behavior: things that react when you click or scroll.

      
Repository ("repo")
A project folder on GitHub that keeps every version of your files.

      
Commit
Saving a change to your repo, with a note about what changed.

      
Hosting / deploy
Putting your site on a computer that's always online. GitHub Pages does this free.

      
Prompt
The instructions you give an AI. Better prompts make better sites.
