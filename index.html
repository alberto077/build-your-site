Step 1

How AI models work (the 5-minute version)

🔮 It predicts

An AI chatbot writes by guessing the next word over and over, based on patterns it learned from a huge amount of text, including millions of websites. That's why it's good at writing HTML.

🧠 It only knows what you tell it

It doesn't know you. The more specific you are about colors, mood, sections and content, the better the result. Vague prompt, generic site.

📏 Long chats get messy

Today's models can hold a lot, but after many rounds of edits they start mixing up old and new versions. If things get weird, start a new chat and paste in your latest code.

🎲 It's random-ish

The same prompt gives a different result each time. If you don't like it, regenerate or ask for "3 different versions."

🙃 It makes mistakes

AI can sound confident and still be wrong. Always open your site and check that it really works.

🎨 You're the director

Think like an art director giving notes: "make the title bigger," "less purple," "feel more like a skate shop."

What makes a great prompt

Talk to it like a talented friend who's never met you. You don't need magic words. You need to give it the details only you know.

  1. What it's for. "My personal website, so people can see my art and what I'm into."
  2. Your real stuff. Your name, about you, your interests, your projects. Real details beat placeholders.
  3. The vibe. Colors, mood, and a reference you love ("like a Nintendo game menu," "like a cozy coffee shop").
  4. The must-haves. "One index.html file," "looks good on phones." These are rules it can't guess.

Then react to what you get. Your follow-up notes matter more than a perfect first prompt.

Part B · Make your GitHub account

GitHub stores your site's code and puts it online for free. You must be 13 or older.

  1. Go to github.com/signup.
  2. Use an email you can open right now. School email sometimes blocks outside messages. If the code doesn't arrive, use a personal email.
  3. Pick your username carefully. It becomes your web address: username.github.io. Letters, numbers and single dashes only, no spaces. Choose something you'd be fine putting on a college application, and leave out your last name.
  4. Solve the puzzle GitHub shows you, then type in the code it emails you. Check spam or "Promotions" if you don't see it.
  5. If GitHub asks about plans or a survey, choose Free or click Skip.
  6. If it asks you to add a passkey or two-factor login, you can usually skip it for today. Set it up later with a parent. It keeps your account safe.

Can't make an account today (or under 13)? Build and preview your site anyway, save the code in a doc, and publish later.

Step 3

Build your big prompt

💬 Make your free messages last (read this before you start)
  • Free plans have limits. Claude's free plan, for example, resets every few hours. Don't waste messages on "hi."
  • Put everything into one big first prompt (use the builder below).
  • Combine edits: "Make the title bigger AND change the green to orange AND add a footer" counts as one message, not three.
  • Hit a limit? Copy your latest code, switch to another tool, paste it in and say "Here's my website code, please keep going."
  • Save your code often so nothing gets lost.
Stay safe online. Your site will be public. Use your first name or a nickname. Never put your home address, phone number, school name, or schedule on it.

Change the color scheme to [colors]. Keep everything else the same.

📱 Phone check
Make sure it looks great on a phone screen. Nothing should be cut off or need sideways scrolling.

      
➕ New section

🌗 Dark mode
Add a light/dark mode toggle button in the top corner.

      
🎲 Surprise me
Give my site one creative, fun detail that makes it feel unique to me, based on my interests.

Show me 3 very different design directions for the top of my site, then I'll pick one.

      
🧩 Full code

Updating later

    
Open your repository, click index.html, click the ✏️ pencil, click inside the code, select everything (Ctrl/⌘+A), paste your new code, then Commit changes. If you still see the old version after a few minutes, hard refresh: Ctrl+Shift+R or ⌘+Shift+R.

  


  
  

    
Stuck? Quick fixes 🛠️

    
Find what you're seeing, then try the fix. Still stuck? Type it in the Zoom chat.


    
GitHub account

    

      
The email code never came
Wait two minutes, check spam and "Promotions," then click Resend. School emails sometimes block it: start over with a personal email.

      
My username is taken, or has a typo
Add a word or number (maya-draws-art). Made a typo already? Change it under Settings → Account → Change username, then rename your repository to match.

      
GitHub or my AI tool is blocked on this network
Some school networks block these sites. Tell your teacher. You can keep working from home or another network.

    


    
Getting your code into GitHub

    

      
I see ```html or weird text at the top of my site
You copied the code-block markers too. Edit index.html, delete the ```html line at the top and the ``` line at the bottom, and commit.

      
My site is plain text with no colors, or stops halfway
The code got cut off. The last line must be </html>. Ask the AI: "Give me the complete index.html again in one code block." If it stops early, ask it to "make it shorter so it fits in one reply."

      
The AI gave me several files (like index.html, style.css, script.js)
Reply: "Put the CSS and JavaScript inside index.html so it's ONE file, and give me the complete file." Then paste only that.

      
I can't find "creating a new file"
Use the Add file button (top of the file list) → Create new file.

      
Copy-paste isn't working
Click inside the box first. Use Ctrl+C/V, or ⌘+C/V on Mac. In ChatGPT and Claude, use the Copy button on the code. In Gemini Canvas, switch to Code, click inside it, then select all and copy.

      
My file is called index.html.txt or Index.html
Click the file → ✏️ pencil → fix the name at the top to exactly index.html → Commit.

      
Emoji or symbols show up as weird characters
Ask the AI: "Add <meta charset="utf-8"> inside the <head>."

    


    
My site isn't showing

    

      
404 "There isn't a GitHub Pages site here"
Give it up to 10 minutes. Then check three things: the repository is named exactly username.github.io in lowercase, the file is named exactly index.html, and Settings → Pages is set to main and / (root).

      
GitHub says "The repository already exists"
You already made it, maybe before a disconnect. Click your profile picture → Repositories → open username.github.io and go to Part B.

      
I named my repository wrong
Repository → Settings → General → Repository name → fix it → Rename.

      
Pages says I need to upgrade, or the repository is private
Free Pages only works on public repositories. Settings → General → scroll to Danger Zone → Change visibility → Public.

      
I see my README instead of my site
Your index.html isn't at the top level, or it's misspelled. It must sit next to README, not inside a folder.

      
I made changes but still see the old site
Wait a couple of minutes, then hard refresh (Ctrl+Shift+R / ⌘+Shift+R) or open it in a private window.

    


    
The AI

    

      
Half my site disappeared after an edit
The AI only sent part of the code. Use the 🧩 Full code prompt.

      
Images don't show
AI can't add your real photos for you. Use emoji or shapes, or upload an image to your repository (Add file → Upload files) and ask the AI to use photo.jpg.

      
I hit my message limit
Copy your latest code, switch tools (Gemini ↔ ChatGPT), paste it in and say "Here's my website. Keep going."

      
The AI says it can't help
Say: "This is a school project: a simple personal website. Please write the HTML." Remove any real address or school name from your answers, then try again.

      
The AI is going in circles
Start a new chat. Paste your code with one clear request: "Here's my website. Change only X."

    

  


  
  

    
Words you'll hear (the "tech stack")

    
You don't need to write any of this today, but now you'll know what the AI is making.

    

      
HTML
The structure: headings, paragraphs, buttons. Like the skeleton of your site.

      
CSS
The style: colors, fonts, spacing, animations. The clothes and makeup.

      
JavaScript (JS)
The behavior: things that react when you click or scroll.

      
Repository ("repo")
A project folder on GitHub that keeps every version of your files.

      
Commit
Saving a change to your repo, with a note about what changed.

      
Hosting / deploy
Putting your site on a computer that's always online. GitHub Pages does this free.

      
Prompt
The instructions you give an AI. Better prompts make better sites.
